Адаптивная страница, разработанная в рамках тестового задания для студии «Гротеск». Проект демонстрирует навыки вёрстки по макету Figma и реализацию интерактивных элементов на нативном JavaScript.

## 📝 Описание

Проект представляет собой одностраничный сайт, свёрстанный по макету в Figma.

## ✨ Функциональность

В проекте реализованы следующие интерактивные элементы:

*   **Модальное меню** — бургер-меню с плавным появлением, навигацией по странице и автоматическим закрытием при выборе пункта.
*   **Переключатель (Switch)** — изменяет цвет элемента «Block» с цветного градиента на фирменный `Color2/Main` и обратно.
*   **Горизонтальный слайдер** — прокрутка карточек с помощью кнопок «Вперёд/Назад» и поддержка перетаскивания (drag-and-drop).
*   **Аккордеон (FAQ)** — блок часто задаваемых вопросов с анимированным раскрытием ответов при клике по заголовку.
*   **Валидация и маски ввода** — умная обработка полей формы: ввод только букв с авто-заглавной для имени и фамилии, автоматическая маска для номера телефона и базовая фильтрация email-адреса.
*   **Плавная навигация** — кнопки для мгновенного скролла к форме и следующему блоку.
*   **Адаптивность** — корректное отображение на всех устройствах с использованием гибкой верстки, медиа-запросов и относительных единиц (`clamp`, `vw`).

## 🛠️ Технологии

*   **HTML5** — семантическая, валидная вёрстка.
*   **CSS3** — Flexbox, CSS-переменные, градиенты, `clamp()` и `media` для адаптивной верстки.
*   **JavaScript (ES6+)** — вся логика реализована на чистом JS без использования сторонних библиотек.
